(`core/data/src/main/assets/places.tsv`), generated by `tools/places/build_places.py` from the sources
below. These notices must be shown in the app's About → Open-source licences screen.

## Time zone rules

Offsets are never stored; they are computed at run time from the device's tz database (IANA tzdb, public
domain) through `java.time`.

## Not used

OpenFlights (`airports.dat`) is intentionally not used: its code is AGPL-3.0 and its data ODbL
(share-alike), which would impose obligations on the app.
